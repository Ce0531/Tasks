# 2️⃣阶段二  
## 1.输入错误文件名  
   - mv 错误文件名 正确文件名  
   - git commit -m "fix: 修改文件名"
## 2.换行符警告  
   - 不影响功能，系统兼容性提示  
## 3.本地分支上游丢失  
   - git branch --unset-upstream（upset与uostream中间没空格） 
   - git checkout main  
   - git merge master  
   - git push origin main  
## 4.同步远程问题  
   - 在Bash或VSCode终端执行：git push origin main  
   - VSCode记得同步，不能光保存本地仓库就以为上传到远程  
## 5.冲突  
   - 打开冲突文件，手动编辑  
   - git add 冲突文件名  
   - git commit -m "fix:解决文件冲突"  
   - git push origin main
