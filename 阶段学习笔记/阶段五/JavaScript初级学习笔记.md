# JavaScript 初级学习笔记  
---
## 一、函数基础
### 1. 函数的概念与封装
- 函数：用来实现某个特定功能的代码块，可以重复调用
- 函数封装：把一个或多个功能打包进函数，对外只保留简单的调用接口，使用者不用关心内部实现细节
### 2. 函数的声明与调用
#### （1）命名函数声明
```js
function 函数名() {
    //函数体代码
}
```
- `function`是声明函数的关键字，必须小写
- 函数名一般命名为动词，比如`getSum`、`getDate`
#### （2）函数表达式（匿名函数）
```js
var 变量名 = function() {
    // 函数体代码
}
```
- 变量名就是调用时使用的名称，里面存储的是函数本身
- 同样支持传递形参、接收实参
#### （3）调用函数
```js
函数名();
```
- 只声明函数不会执行代码，必须调用才会执行函数体
- 调用时不能忘记写小括号
### 3. 函数的参数
#### （1）形参与实参
|参数类型|说明|
| ---- | ---- |
|形参|函数定义时括号里的占位参数，定义时不知道具体值|
|实参|函数调用时传入的真实数据，调用时会传递给对应的形参|
- 参数作用：函数内部值不固定时，通过参数传入不同数据，让函数更灵活
- 多个参数之间用逗号分隔，形参和实参数量尽量匹配
#### （2）arguments的使用
- `arguments`是函数内置的伪数组对象，保存了所有传入的实参
- 特点：有`length`属性，可以通过索引访问，但没有数组的`push`、`pop`等方法
- 用途：不确定传入多少个实参时，用`arguments`接收全部参数
```js
function fn() {
    for(var i = 0; i < arguments.length; i++){
        console.log(arguments[i]);
    }
}
fn(1,2,3);
```
### 4. 函数的返回值return
1. **返回结果**：把函数执行结果返回给调用者，`函数名()`的结果就等于return后面的值
```js
function getResult() {
    return 666;
}
console.log(getResult()); //输出 666
```
2. **终止函数**：return语句之后的代码不会再执行
3. **单次返回**：return一次只能返回一个值；逗号分隔多个值时，只返回最后一个
4. **无返回值**：函数没有写return时，默认返回`undefined`
5. **返回多个值**：可以用数组包裹多个结果返回
```js
function getResult(num1, num2) {
    return [num1 + num2, num1 - num2, num1 * num2];
}
```
### 5. break、continue、return的区别
|关键字|作用范围|效果|
| ---- | ---- | ---- |
|`break`|循环体|结束当前整个循环|
|`continue`|循环体|跳出本次循环，继续下一次循环|
|`return`|函数内部|结束整个函数 + 返回指定值|

## 二、变量作用域与预解析
### 1. 作用域的分类（ES6 之前）
- **全局作用域**：作用于整个script标签或单独的JS文件
- **局部作用域（函数作用域）**：只在函数内部生效
### 2. 全局变量与局部变量
#### （1）全局变量
- 在函数外部、全局作用域声明的变量
- 代码任何位置都可以使用
- 只有关闭浏览器时才会销毁，相对占内存
- 特殊情况：函数内部不写`var`直接赋值的变量也会变成全局变量（不推荐）
#### （2）局部变量
- 在函数内部声明的变量，函数的形参也属于局部变量
- 只能在当前函数内部使用
- 函数执行结束就会自动销毁，更节省内存
### 3. 作用域链
- 函数内部可以嵌套函数，形成多层作用域
- 内部函数访问变量时，会从内到外逐层向上查找（链式查找），这种机制就是作用域链
- 查找规则：就近原则，内层找不到就往上一层找，直到全局作用域
### 4. 预解析（变量提升和函数提升）
JS 引擎执行代码分为两个阶段：
1. **预解析**：把所有`var`变量声明、`function`函数声明提升到当前作用域最顶部
   - 变量提升：只提升声明，不提升赋值
   - 函数提升：只提升函数声明，不调用函数
2. **代码执行**：从上到下按顺序执行代码

## 三、DOM 基础
### 1. DOM 简介
DOM（文档对象模型）是 W3C 定义的操作网页的标准编程接口，通过 DOM 可以修改网页的内容、结构和样式。
#### DOM 树的组成
- 文档：整个网页，用`document`表示
- 元素：所有 HTML 标签，用`element`表示
- 节点：网页所有内容（标签、文本、属性、注释等），用`node`表示
### 2. 获取页面元素
#### （1）根据 ID 获取单个元
```js
document.getElementById('id名')
```
- 返回单个元素对象，ID 大小写敏感
- `console.dir(元素)` 可以打印元素的完整属性和方法
#### （2）根据标签名获取元素集合
```js
document.getElementsByTagName('标签名')
```
- 返回伪数组形式的元素集合
- 即使只有一个标签、没有匹配标签，返回的也都是伪数组
- 支持在父元素内部调用，只查找父元素内的子标签（父元素必须是单个对象）
#### （3）根据类名获取元素集合
```js
document.getElementsByClassName('类名')
```
- 返回所有匹配类名的元素集合
#### （4）H5 新增选择器（开发最常用）
- `querySelector('选择器')`：返回匹配选择器的**第一个**元素
  - 选择器需要加符号：类名加`.`，id加`#`
- `querySelectorAll('选择器')`：返回匹配选择器的**全部**元素集合
#### （5）获取页面特殊元素
- 获取 body：`document.body`
- 获取 html：`document.documentElement`
### 3. 操作元素内容
|属性|是否识别HTML标签|标准属性|空格换行处理|
| ---- | ---- | ---- | ---- |
|`innerText`|不识别|非标准|去除空格和换行|
|`innerHTML`|识别|W3C 标准|保留空格和换行|
- 两个属性都是可读写的，既可以获取内容，也可以设置新内容
### 4. 操作元素属性
#### （1）普通元素属性
图片的`src`、`title`、`alt`，链接的 `href`等原生属性，都可以直接通过`元素.属性名`读写
```js
img.src = 'images/photo.jpg';
img.title = '图片标题';
```
#### （2）表单元素属性
表单专用属性，不能用`innerText/innerHTML`操作
- `value`：修改输入框、按钮的文字内容
- `disabled`：设置为`true`可以禁用表单元素
- 事件函数内部的`this`，指向触发事件的元素本身
### 5. 操作元素样式
1. **行内样式操作**：`element.style`
   - 样式名采用驼峰命名法，比如`fontSize`、`backgroundColor`
   - 修改的是行内样式，CSS 权重较高
2. **类名样式操作**：`element.className`
   - 通过修改元素类名，切换预设好的CS样式，适合样式修改较多的场景
### 6. 排他思想
#### 适用场景
一组元素中，只让当前被操作的元素拥有特殊样式，其他元素恢复默认。
#### 实现步骤
1. 先清除所有元素的样式
2. 再给当前元素设置样式
> 顺序不能颠倒，必须先全部清除，再设置当前元素

## 四、节点操作
### 1. 节点概述
节点至少拥有三个基本属性：
- `nodeType`：节点类型
- `nodeName`：节点名称
- `nodeValue`：节点值
#### 常见节点类型
|节点类型|nodeType 值|
| ---- | ---- |
|元素节点|1|
|属性节点|2|
|文本节点|3（包含文字、空格、换行）|
- 实际开发主要操作元素节点
### 2. 节点层级
#### （1）父节点
```js
元素.parentNode
```
- 获取离当前元素最近的一级父节点，找不到返回 `null`
#### （2）子节点
- `parentNode.childNodes`：返回所有子节点（包含元素、文本、注释等），开发不常用
- `parentNode.children`：只返回所有子元素节点，开发首选
#### （3）兄弟节点
- `nextElementSibling`：下一个兄弟元素节点
- `previousElementSibling`：上一个兄弟元素节点
- IE9 及以上支持，低版本兼容可以自己封装工具函数
### 3. 创建节点
```js
document.createElement('标签名')
```
- 创建一个全新的 HTML 元素节点
### 4. 添加节点
1. 末尾追加：`父节点.appendChild(子节点)`，添加到子节点列表末尾
2. 指定位置插入：`父节点.insertBefore(子节点, 指定子元素)`，添加到指定子元素前面
> 页面新增元素固定两步：先创建节点，再添加到父节点中
### 5. 删除节点
```js
父节点.removeChild(子节点)
```
- 删除父节点中的指定子节点，返回被删除的节点
### 6. 克隆（复制）节点
```js
节点.cloneNode()
```
- 参数为空/`false`：浅拷贝，只复制标签本身，不复制内部子节点
- 参数为`true`：深拷贝，复制标签+内部所有子节点

## 五、事件基础
### 1. 事件概述
事件是JS可以检测到的用户行为，核心是触发 → 响应机制，用来实现网页的动态交互。
### 2. 事件三要素
1. **事件源**：触发事件的对象，比如被点击的按钮
2. **事件类型**：触发的方式，比如点击、鼠标经过
3. **事件处理程序**：事件触发后执行的代码，以函数形式书写
基础示例：
```js
//1. 获取事件源
var btn = document.getElementById('btn');
//2. 注册事件 + 编写处理程序
btn.onclick = function() {
    alert('触发了点击事件');
}
```
### 3. 执行事件的步骤
1. 获取事件源
2. 注册（绑定）事件
3. 添加事件处理程序
### 4. 常见鼠标事件
|事件名|触发条件|
| ---- | ---- |
|`onclick`|鼠标左键点击|
|`onmouseover`|鼠标经过元素|
|`onmouseout`|鼠标离开元素|
|`onfocus`|元素获得焦点|
|`onblur`|元素失去焦点|
|`onmousemove`|鼠标在元素上移动|
|`onmousedown`|鼠标按键按下|
|`onmouseup`|鼠标按键弹起|
### 5. 事件对象
- 事件触发时系统自动创建，包含事件的全部相关信息
- 写在事件处理函数的形参位置，常用命名`event`、`evt`、`e`
- 低版本 IE 兼容写法：`e = e || window.event;`
#### e.target和this的区别
- `e.target`：返回**真正触发**事件的元素（点到哪个就是哪个）
- `this`：返回**绑定了事件**的元素（谁绑定事件就返回谁）

## 六、事件高级
### 1. 注册事件的两种方式
|对比项|传统注册方式|方法监听注册方式|
| ---- | ---- | ---- |
|写法|`btn.onclick = function(){}`|`btn.addEventListener('click', function(){})`|
|特点|同一元素同一事件只能绑定一个处理函数，后面的覆盖前面的|同一元素同一事件可以绑定多个处理函数，按顺序执行|
|兼容性|所有浏览器支持|IE9及以上支持，旧版 IE 用`attachEvent`|
|标准性|传统写法|W3C标准，推荐使用|
### 2. 删除事件（解绑事件）
1. 传统方式：`eventTarget.onclick = null;`
2. 方法监听方式：`eventTarget.removeEventListener(type, 处理函数)`
   > 解绑的处理函数必须和绑定时是同一个命名函数，匿名函数无法解绑
### 3. 注册事件兼容方案
遵循"先兼容主流浏览器，再处理特殊浏览器"的原则
```js
function addEventListener(element, eventName, fn) {
    if (element.addEventListener) {
        element.addEventListener(eventName, fn);
    } else if (element.attachEvent) {
        element.attachEvent('on' + eventName, fn);
    } else {
        element['on' + eventName] = fn;
    }
}
```
### 4. DOM 事件流
事件发生时，在元素节点之间按特定顺序传播的过程，就是DOM事件流。

#### 三个阶段
1. **捕获阶段**：从document顶层从上往下传播到目标元素
2. **目标阶段**：事件到达触发事件的元素本身
3. **冒泡阶段**：从目标元素从下往上传播回document顶层
- `addEventListener`第三个参数`useCapture`：`false`为冒泡阶段（默认），`true`为捕获阶段
### 5. 阻止事件冒泡
- 标准浏览器写法：`e.stopPropagation();`
- IE6-8 兼容写法：`e.cancelBubble = true;`
- 封装兼容函数：
```js
function stopBubble(e) {
    if(e.stopPropagation){
        e.stopPropagation();
    }else{
        e.cancelBubble = true;
    }
}
```
### 6. 阻止默认行为
默认行为：标签自带的原生行为，如a标签跳转、表单提交、右键菜单
- 标准：`e.preventDefault();`
- IE低版本：`e.returnValue = false;`
- 简易写法（传统绑定事件内）：`return false;`
### 7. 事件委托（事件委派）
#### 原理
利用事件冒泡，只给父元素绑定一次事件，由父元素统一处理所有子元素的事件。
#### 优势
1. 只绑定一次事件，节省内存，提升性能
2. 后续动态新增的子元素也能自动拥有事件，无需重复绑定
#### 核心判断
通过 `e.target`判断点击的子元素类型，执行对应逻辑
示例：
```js
var ul = document.querySelector('ul');
ul.addEventListener('click', function(e){
    if(e.target.tagName === 'LI'){
        alert('点击了li标签');
    }
})
```
### 8. 常用鼠标高级事件
1. `contextmenu`：右键菜单触发，可阻止默认右键菜单
2. `selectstart`：文字选中时触发，可禁止页面文字复制选中
### 9. 鼠标坐标
|属性|坐标说明|
| ---- | ---- |
|`e.clientX / clientY`|可视窗口左上角为原点，不计算滚动距离|
|`e.pageX / pageY`|整个页面左上角为原点，包含页面滚动距离（常用）|
|`e.screenX / screenY`|电脑屏幕左上角为原点|

## 七、事件对象常用属性汇总
|属性/方法|作用|
| ---- | ---- |
|`e.target`|实际触发事件的元素|
|`e.type`|获取当前触发的事件类型（不带on）|
|`e.preventDefault()`|阻止元素默认行为|
|`e.stopPropagation()`|阻止事件冒泡|
|`e.clientX`|鼠标距离视口左侧距离|
|`e.clientY`|鼠标距离视口顶部距离|
