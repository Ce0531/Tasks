# 4️⃣阶段四  
## 1.Q&A 折叠面板点击展开异常  
 - 问题：点击问题标题后，回答区域仅轻微下移，无法完整显示内容；多次修改样式后仍出现展开不完整、动画失效、无响应等情况  
 - 原因：CSS过渡属性与实际变化属性不匹配使用`transition: transform`却修改`height`，导致浏览器无法识别动画。`height: auto`不支持CSS过渡,CSS 无法对`0 → auto`进行插值计算，导致高度无法正确撑开。JS与CSS控制逻辑冲突,JS直接控制`display`，CSS控制`height/max-height`，两套规则互相覆盖。不合理内边距导致内容挤压,展开状态设置过大`padding`，使内容区域被压缩或超出可视范围    
 - 解决：JS 只负责切换类名，CSS 负责所有样式与动画
      
 - css    
  ```css
  .qa-a {
  max-height: 0;
  overflow: hidden;
  transition: max-height 0.4s ease, padding 0.4s ease;
  padding: 0 20px;
  }
  .qa-item.active .qa-a {
  max-height: 800px;
  padding: 20px;
  }  
  ``` 

 - js  
  ```javascript  
  const items = document.querySelectorAll('.qa-item');
  items.forEach(item => {
    item.querySelector('.qa-q').addEventListener('click',    () => {
      item.classList.toggle('active');
     });
   });   
   ```

## 3.class 与 id 选择器优先级与样式覆盖  
 - 问题：部分样式不生效，控制台查看样式被划掉，出现样式覆盖  
 - `!important` > 行内样式 > ID 选择器 > 类 / 属性 / 伪类 >  标签选择器  
## 4.DOM加载顺序导致JS获取不到元素  
 - 问题：控制台报错：无法读取 null 的属性，事件绑定无效   
 - 解决：将`<script>`放在`</body>`结束标签前  
 - 操作DOM必须保证节点已生成    
## 5.盒模型导致布局宽度计算错误  
 - 原因：默认盒模型`box-sizing: content-box：`  
 - 实际宽度 = width + padding + border  
 - 解决：  
   ```css  
   * {
     box-sizing: border-box;
   }  
   ```

## 7.控制锚点跳转速度  
 1. CSS的局限  
   - CSS的核心作用是控制元素的样式和布局，而非控制页面的滚动行为。CSS中没有任何属性或语法可以直接定义 页面滚动到某个元素的速度、动画效果    
   - `scroll-behavior: smooth`：CSS这个属性能实现平滑跳转，但无法控制速度,它是浏览器内置的固定速度，开发者不能自定义时长、缓动效果，也无法精准调整跳转节奏  
   - 无法精准控制起始位置和对齐方式：CSS平滑跳转只能默认对齐目标元素，无法像JS那样灵活设置`start`/`center`/`end`对齐  
   - 无法实现自定义逻辑：比如跳转完成后触发元素聚焦、滚动过程中改变导航栏样式等，CSS无法完成这类交互逻辑   
 2. 用JS实现  
- 方法一：原生JS平滑滚动（scrollIntoView）  
   ```javascript  
   // 给目标锚点元素添加点击事件（以 About US 为例）
   document.querySelector('.nav-link[href="#about"]').addEventListener('click', function(e) {
      e.preventDefault(); // 阻止默认瞬间跳转
      // 平滑跳转到目标锚点
      document.querySelector(this.getAttribute('href')).scrollIntoView({
         behavior: 'smooth', // 平滑滚动关键字
         block: 'start' // 对齐方式：目标元素顶部对齐视口顶部
      });
   }); 
   ```
-  方法二：自定义动画滚动（控制速度的精准方案）  
  ```javascript  
  // 自定义平滑滚动函数（可精准控制速度）
  function smoothScrollTo(targetId, duration = 500) {
      const target = document.querySelector(targetId);
      if (!target) return;

      const start = window.scrollY; // 滚动起始位置（当前页面滚动条距离）
      const end = target.getBoundingClientRect().top + window.scrollY; // 目标元素距离页面顶部的总距离
      const startTime = performance.now(); // 动画开始时间戳

      // 动画帧函数：逐帧计算滚动位置
      function animateScroll(currentTime) {
         const elapsed = currentTime - startTime; // 已消耗时间
         const progress = Math.min(elapsed / duration, 1); // 滚动进度（0-1之间）
         const easeProgress = progress; // 可替换为缓动公式（如 progress * (2 - progress) 实现缓动）

         // 计算当前滚动位置：起始位置 + 总距离 * 进度
         window.scrollTo(0, start + (end - start) * easeProgress);

         if (progress < 1) {
            requestAnimationFrame(animateScroll); // 继续下一帧动画
         } else {
            target.focus(); // 滚动完成后聚焦目标元素，提升可访问性
         }
      }

      requestAnimationFrame(animateScroll); // 启动动画
   }

   // 绑定所有锚点链接的点击事件
   document.querySelectorAll('.nav-link').forEach(link => {
      link.addEventListener('click', function(e) {
         e.preventDefault();
         const targetId = this.getAttribute('href');
         smoothScrollTo(targetId, 600); // 传入目标锚点，自定义时长（单位：毫秒，数值越大速度越慢）
      });
   });
   ```
